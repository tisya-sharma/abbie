# Source PDFs

Full texts of closed-access papers cited by the corpus, retrieved under institutional licence.

**Nothing in this directory is committed.** These are copyrighted works and this repository is
written to be public. The directory exists so that claims requiring full-text verification have
somewhere to be verified from; the citation itself lives in the concept's frontmatter, which is
what ships.

Naming is `short-year.pdf`, matching the `short` field of the source row that cites it.

Which claims need full text rather than an abstract is governed by the sourcing rule: any number,
denominator, threshold, stated condition, negative result or limitation needs the full text.
Directional and definitional claims may rest on an abstract, written as attributed statements.
